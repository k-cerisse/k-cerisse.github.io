VO₂ Analysis Tool

About this tool

This tool runs a Python script directly in the browser to analyse metabolic data collected during exercise testing. Upload a CSV exported from a metabolic cart and click Run Analysis to generate three plots:

  • Plot 1 — VO₂ over time (oxygen consumption, L/min)
  • Plot 2 — FECO₂ vs VO₂ (fraction of expired CO₂)
  • Plot 3 — VCO₂ vs VO₂ (CO₂ production vs O₂ consumption)
CSV format

The file must contain the following columns with these exact names:

TIME VO2 FECO2 VCO2

The first row must be the column header. Rows 2–4 may contain sub-headers, units, or separators — these are automatically skipped.
